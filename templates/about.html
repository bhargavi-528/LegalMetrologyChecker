Packaged Commodity Compliance Checker

AI-assisted image and label analysis for preliminary packaged commodity compliance assessment.

The Problem

Inspecting large numbers of packaged commodities manually can be time-consuming and resource-intensive.

Our Approach

The system combines image processing, OCR, information extraction, rule-based validation and visual analysis.

Workflow

Scan → Extract → Validate → Analyse → Report

Technology

Python, Flask, EasyOCR, OpenCV, JavaScript, HTML, CSS and SQLite.
